> I build AI-powered products end to end — from the Supabase schema to the Vercel deploy. My work combines React frontends, n8n automation pipelines, and real user feedback loops to ship things that actually work.

Focused on **health-tech** and **AI automation**. Currently building The Gibborim, a community fitness app for the MENO global outreach ministry, alongside MENMED (B2B medical equipment sales) and LeadGen Pro (AI lead generation micro-SaaS with n8n + Supabase webhooks).

## Projects

| Project | What it does | Stack |
|---|---|---|
| [MENMED](https://menmed-website.vercel.app) · **Live** | B2B medical equipment sales platform. Quote-request modal writes to Supabase in real time. Built for hospital procurement teams across Africa. | React, Vite, Tailwind, Supabase |
| [LeadGen Pro](https://leadgen-pro-tau.vercel.app) · **Live** | AI lead generation micro-SaaS. n8n webhook pipeline captures and qualifies leads automatically. Supabase stores and routes them in real time. | n8n, Supabase, React, Vercel |
| The Gibborim · *In Dev* | Community fitness app for MENO global outreach ministry. 7-day warrior workout plan with fitness-level-aware programming (beginner/intermediate/expert), equipment mode switching, and Supabase-backed user profiles. | React, Vite, Tailwind v4, Supabase |
